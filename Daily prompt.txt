Read seo_context.md and the last three reports in seo_reports/.

──────────────────────────────────────────
STEP 1 — DID THE USER BRING DATA?
──────────────────────────────────────────

Check whether the user's message contains pasted stats (GSC queries,
install numbers, review count, or outreach reply). If yes, jump to STEP 2.
If no, skip to STEP 3.

──────────────────────────────────────────
STEP 2 — ANALYSE THE DATA (only if stats were provided)
──────────────────────────────────────────

Analyse what the numbers actually say. Be specific:
- Which keywords are getting impressions but no clicks? (CTR problem)
- Which pages are indexed vs not? (coverage gap)
- Is install growth accelerating, flat, or dropping?
- Did any outreach convert?

Give ONE concrete recommendation that follows directly from the data.
Save the report and stop — skip STEP 3 and STEP 4.

──────────────────────────────────────────
STEP 3 — RESEARCH (when no data was provided)
──────────────────────────────────────────

Do a focused scan. Only flag things that have genuinely changed since
the last report:
- Any competitor update not already in seo_context.md?
- Any new roundup or mention found?
- Any keyword gap in the listing or website not previously identified?
- Any recent app changes (check git log) worth surfacing in SEO?

If nothing has changed: say so in one sentence. Do not restate things
already in seo_context.md as if they are new findings.

If something has changed: give ONE specific recommendation, fully written
out (exact copy, exact post text, exact outreach message) — not described.

──────────────────────────────────────────
STEP 4 — DATA REQUEST (end of every session)
──────────────────────────────────────────

Every session ends with a data request under the heading "For next time:"

Check the last five reports and pick whichever request below has gone
the longest without being answered. The user will fetch it before the
next session and paste it in.

A) GSC queries — "Go to search.google.com/search-console → Performance →
   Last 28 days → Queries tab. Paste the top 10 queries by impressions
   with click count and CTR."

B) GSC indexing — "Go to search.google.com/search-console → Indexing →
   Pages. How many pages are now indexed? Has anything moved out of
   'Discovered - currently not indexed'?"

C) Play Store — "Go to play.google.com/console → Metro Gnome → Statistics.
   Paste the current install count, 28-day new installs, and rating + review count."

Do not ask for the same one two sessions in a row.

──────────────────────────────────────────
STEP 5 — SAVE REPORT
──────────────────────────────────────────

Save to seo_reports/YYYY-MM-DD.md.
Update seo_context.md only if something genuinely changed.
Keep it short. A quiet day should be a short report.
