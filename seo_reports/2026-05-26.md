## Recommendations

### a) ASO — add "practice streak" to long description feature bullets

The Play Store long description lists core features but does not mention the practice streak tracker. No app in any of the four roundups checked today offers a streak mechanic — it's genuinely unique to Metro Gnome among pure metronome apps.

Adding one line (e.g. *"Practice streak tracker — build a consistent daily habit and watch your streak grow"*) targets the "music practice habit" / "consistent guitar practice" intent that musicians search for separately from metronome queries. It's also a concrete, differentiating claim that roundup authors can use as a reason to include Metro Gnome over otherwise-similar apps. Zero cost, no short-description change needed.

### b) Content — blog post: "The Best Free Chromatic Tuner App for Android (No Subscription, No Paywall)"

Pano Tuner — previously the default "just use this free tuner" recommendation — is now actively frustrating users with features locked behind paywall that were previously free. Users are searching for alternatives *right now*. A post targeting "free chromatic tuner android" or "chromatic tuner app no subscription android" would:

1. Rank for a real search query with live user pain behind it.
2. Directly contrast Metro Gnome's "core experience is fully free — no subscription, ever" with Pano Tuner and Soundcorset's patterns.
3. Provide non-spammy link material for Reddit threads where users ask "what's a good free tuner that actually works?"

Different angle from both existing tuner posts (noisy room May 20; wrong note May 25). Check `landing/blog/` before drafting to confirm no overlap.

### c) Code — add V4_5 What's New entry to `AppWhatsNew.kt`

The tuner precision fix (inTuneCents 1.5 → 3.0¢) is the most tangible UX improvement in v4.5 — users who previously saw the green indicator flicker on and off will notice it now holds. Surfacing this via a What's New card converts an invisible background fix into an active retention signal ("the tuner improved") rather than a silent update.

Steps (small change):
1. `whatsnew/AppWhatsNew.kt`: add `const val V4_5 = "v4_5"` and append to `ALL` list.
2. `ui/overlays/FeatureIntroOverlay.kt`: add a V4_5 card branch — one headline ("Tuner holds green longer"), one line of explanation, no technical jargon.
3. `viewmodel/MetronomeViewModel.kt` or `WhatsNewTracker.kt`: wire V4_5 the same way V4 was wired.
