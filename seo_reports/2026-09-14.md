## 2. Findings

1. **The odd meter tool broke the tools pattern.** 157 impressions, 0 clicks, now the third
   highest-impression page on the site with the worst CTR; the rhythm test converted at 26%
   off its first 30. Diagnosis: the queries it earns ("odd meter", "odd meters", "compound time
   signatures", "simple meter") are definition queries and the snippet offered a practice tool
   for a thing the searcher does not yet understand. The rhythm test's title is a question
   matching a question query, which is why it converts. **Fixed today** (see 3.1). This is a
   snippet-intent fix on the tool page, not a rewrite of the explainer, so the standing
   "do not rewrite time-signatures-explained" verdict is untouched.
2. **The drone cluster earns.** 2/22 in ten days on the post, which is the trigger the 09-03
   entry set for building the browser drone. **Built today** (see 3.4).
3. **Brand queries are now ~1,000 impressions and 25 of 104 clicks**, and the no-space query
   converts. Nothing to do; logged so nobody reopens the collision item.
4. **Internal linking remains the only lever that has ever moved position**, and the
   homepage topic index had no tools card. Added one today.

### 3.4 Tuning drone tool (task 7)
`tools/tuning-drone.html` plus `embed/tuning-drone.html` (fourth widget, generator updated).
Ports `DroneVoice.kt`'s Pure and Warm timbres and Root/Octave blends exactly (partials,
strand detunes, LFO rates, equal-power pan, power-summed normalisation to 0.22 RMS); Reed,
String and Fifth stay app-only and are shown as disabled chips that say so. Keyboard C to B
with letters (a web page cannot rely on keyboard geometry the way the app's drawn keyboard
can), octave 2-5, A4 415-466, level slider, arrow keys step semitones. Nothing steps: raised
cosine start/stop, exponential (log-frequency) glide on note or reference change, one-pole
level, linear crossfade on voice change (the two voices are correlated, so equal-power would
bulge). **Verified by measurement, not by ear**: an analyser on the master gain read A3 at
A4=415 as 207.49 Hz with the octave at 415.01 Hz and no other peaks, and exactly 0.0 RMS
after stop, so a voice swap leaves no oscillator running. Widget heights measured in-browser:
925 at 480px, 1110 at 300px.
